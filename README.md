# RECEBIMENTO-LM-SES3

Portal de recebimento de pacotes com sincronização central entre celulares e computadores.

- Frontend: GitHub Pages (`index.html`)
- API: Cloudflare Worker (`src/worker.js`)
- Banco: Cloudflare D1
- Retenção operacional: 180 dias
- Acesso: senha do portal com sessão temporária; nenhum PAT do GitHub é necessário nos aparelhos

Os segredos de produção são mantidos exclusivamente pela Cloudflare e não devem ser adicionados ao repositório.
